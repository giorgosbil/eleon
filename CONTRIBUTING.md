# Contributing to Eleon

Thank you for helping shape Eleon. The first public Free-core source release is
still being prepared; application code contributions will open with that release.

For now, useful contributions include feedback on the product demo, unclear
documentation and proposed use cases. Check existing issues before opening one.
Describe the problem, the expected behavior and an example using fictional data.

For documentation changes, fork this repository, create a branch and open a pull
request explaining the change. Keep changes focused. Submit only material you
have permission to share under the repository's license; retain third-party notices.

Never include real mailbox contents, customer records, credentials, local runtime
data or proprietary Pro/Business source. Security concerns belong in the private
reporting channel in SECURITY.md, rather than a public issue.
