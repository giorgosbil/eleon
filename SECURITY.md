# Security reports

No public application version has been released from this repository yet.
Supported versions and update guidance will be listed with the first release.

Report suspected vulnerabilities privately to **georgebilalis@hotmail.com**, with
the subject "Eleon security report". Include affected versions (if known), a
description, impact and reproduction steps using synthetic data.

Do not open a public issue containing exploit details, email content, credentials,
tokens or other personal data. We will review the report and coordinate next steps.
